# Roadmap

Planned features and improvements for **MotoGP VideoPass for Kodi**. Items are ordered roughly by priority, not by timeline.

## Short term

- [ ] Repository add-on (`repository.ypoulis`) for one-click install + auto-updates
- [ ] Better event browsing (filters, search, jump-to-current-weekend shortcut)
- [ ] Resume playback across sessions (per-session bookmarking)

## Medium term

- [ ] Richer metadata in Now-Playing (riders, lap counts, duration)
- [ ] Better artwork: track maps, event posters
- [ ] Optional pre-fetching of upcoming live sessions

## Longer term

- [ ] Smarter quality selection (auto / network-aware)
- [ ] Catalog content beyond races (interviews, documentaries) where available
- [ ] Skin-friendly metadata for better integration with custom Kodi skins

Have an idea? Open a [feature request](https://github.com/ypoulis-hub/kodi-motogp-videopass/issues/new?template=feature_request.md) or start a thread in [Discussions](https://github.com/ypoulis-hub/kodi-motogp-videopass/discussions).
