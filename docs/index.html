Installation

Recommended — via the YPoulis Kodi Repository

Install the repository once and Kodi keeps this add-on (and the YouTube Music add-on) up to date automatically.

  1. Download repository.ypoulis-1.0.0.zip from the repository site.
  2. In Kodi → Settings → Add-ons → Install from zip file → pick the downloaded ZIP.
  3. Then Install from repository → YPoulis Kodi Repository → Video add-ons → MotoGP VideoPass.
  4. Paste your VideoPass DAT cookie into authentication settings — see the README.

Open the repository landing page →

Alternative — manual ZIP install

  1. Download the latest plugin.video.motogp-x.y.z.zip from the Releases page.
  2. In Kodi → Settings → Add-ons → Install from zip file → pick the ZIP.
  3. Open the add-on under Video add-ons.
  4. Paste your VideoPass DAT cookie into authentication settings.

Manual installs do not auto-update.

FAQ

Is this an official MotoGP VideoPass add-on?

No — this is an unofficial Kodi add-on. It is not affiliated with MotoGP, Dorna Sports or VideoPass.

Do I need a MotoGP VideoPass subscription?

Yes. Both VOD and live playback require an active VideoPass subscription tied to the cookie you provide.

Does it stream live races?

Yes. Since v0.2.0 a ● Live entry appears at the top of the main menu when a session is live on motogp.com.

Does it support replays?

Yes — browse by season → event → category to find races, qualifying, practice and sprint sessions.

Does it work on Kodi 21 Omega?

Yes — Kodi 21 Omega is the primary target.

Does it work on LibreELEC?

Yes — it is regularly tested on LibreELEC running Kodi 21.
